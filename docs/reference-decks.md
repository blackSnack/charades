# Four reference-deck experiment — design handoff

The four supplied concept boards are the visual source: Balatro paper/foil/holographic/negative ember, GWENT parchment/steel/silver-gold/masterwork, Monster Train old brass/smoke iron/crimson brass/molten iron, Inscryption paper/bone/wood/ritual. These are original interpretations, not game artwork or extracted game shaders. The supplied boards have mixed portrait/landscape templates; gameplay retains its existing landscape-adaptive dimensions and oversized Chinese word. No word-specific illustration, logo, or hint; decoration is redrawn in SVG rather than using a flattened concept-board image.

Implementation: geometry measured from the card; 16 explicit material rows; corner motifs mirror without stretching, straight rails adapt. Independent live word above art and GPU. GLSL signed-distance rim mask, foil specular, spectral shift, warm metal, noise-driven heat seams and candle flicker; bounded procedural perimeter particles. Low/off, hidden/reduced motion and WebGL loss fallback. Static gallery uses no GPU instances. No additional dependencies. Existing game rules, default theme and previous preferences preserved.

## Visual review gate

Target requested: 90–95% visual fidelity. This is a target, **not an automatic score**. Compare screenshots side by side to original concept boards after adapting the aspect ratio. Score per family/level: silhouette/ornament 25, material texture and depth 30, palette/contrast 20, motion/edge anchoring 15, word legibility 10. Art approval requires reviewer signoff; screenshot comparison alone does not establish fidelity. The automated test checks material identity, card geometry, visible word, screenshot all levels, real edge alpha and temporal variation, zero central GPU alpha. The first approved captures can become future pixel-diff baselines, not a substitute for review against the concept board. Real iPhone GPU performance is separate.

No approved fidelity score yet. Keep as an experimental candidate until reference review.

Palette diagnostics are measured against medians of actual reference-board card crops (paper patch x=.30–.70/y=.27–.34; left rim x=.02–.045/y=.30–.70). Browser screenshots sample the same normalized regions with the word hidden temporarily. CIE76 ΔE is reported separately for paper/rim in reference-color-diagnostics.json. Because the source layouts differ from runtime and the reference has ornate depth, these color distances are diagnostic rather than a percentage fidelity score. The full screenshots include the real word and are the review evidence.

## Hybrid art pipeline
The four actual concept boards are checked in at design/reference-decks (JPEG renditions, not runtime resources). Run pip install -r scripts/deck-art-requirements.txt then python scripts/build-deck-art.py to reproduce public/deck-art/v1 before npm run build. Inpainting removes the sample word; tier plaques remain fixed artwork, the corresponding HTML difficulty remains accessible. Source aspect ratio is adapted by a 5x3 piecewise stretch that preserves corners and the central plaque. Each tier has one WebP plate and a separate packed, height-derived normal XY + warm emissive texture. GLSL adds actual rim-bound dynamic light and particles; the plate remains static with quality off or when WebGL is unavailable. Maps fetched only when animation is active. Asset cache is separate and excluded from precache. No fixed sample word in artwork. The source plate agreement outside the inpaint mask measures preservation of reference pixels, not perceived overall fidelity of resized cards or motion. The prior 90–95% subjective visual target still needs actual screenshot review.

## v3.1.7 narrow flowing highlight hotfix
The published v3.1.6 uses the full rim SDF mask plus baseline tint, specular alpha and emissive alpha. It starts after flipDone, and the map upload can add more alpha. This creates an unwanted secondary frame. On the release baseline only, replace the broad rim with a single arc-length-following highlight, centered 1.8 CSS px inside the rounded card, max 2.9 px geometric support, tapered over about 20.5% of perimeter. No fixed opacity, no halo, no additional particle ring. The original decorative artwork is unchanged. Start on reveal with a 240ms fade; relief map may affect local color only. The low/high quality choices preserve the same geometry. Browser readPixels checks max 4 CSS px (raster tolerance), normalized coverage <.35, moving centroid, no central alpha, and checks again after 1.1s; screenshots capture actual rendered result. This scoped hotfix does not include draft #10's separate geometry or fidelity changes.

## v3.1.8 — use upstream Shine Border
User rejected the v3.1.7 arc-length light as snake-like. Replace only the four reference families' animated edge with actual Magic UI ShineBorder (MIT), not another custom path shader. Its original 300% radial-gradient field, content-box exclusion mask and 0%/50%/100% background-position keyframes are retained. The 1px ring is a mask, not a new opaque border. 12s full / 16s low, muted theme colors, no extra outline or halo. No live normal-map fetch or WebGL context for these families; retain generated map assets for the separate art pipeline and draft review work. Simple/off/reduced-motion retain static plates. Browser tests inspect true animation progression and compare actual masked screenshot pixels at three phases against the same card with shine hidden. Existing gameplay and other deck renderers unchanged. Final subjective motion acceptance remains on-device.

## v3.1.9 — art readiness and visible shine
The previous code only mounted the plate request after reveal, exposing a generic fallback before the actual ornament was painted. Keep the reference frame mounted behind the card back, share decoded images and pending requests by tier, warm only the selected family at selection or saved-theme startup, and gate actual reveal on successful canvas paint (not network completion). An 8s timeout or request/decode failure uses a stable, explicitly labeled fallback for that card; a new card can retry. No placeholder-to-art swap mid-reveal. Original art/crop geometry unchanged. Magic UI gradient mask stays; full 2px/4.8s, low 1.5px/6s, stronger material-specific highlights; gallery follows quality and reduced motion. Remove favorites UI and obsolete data on next preference save; old records still load theme/quality.
